## 1. Загальні положення. 
Цей документ описує єдині стандарти написання коду для проєкту "OnlineCourses". Мета — забезпечити читабельність, передбачуваність та легкість підтримки коду. Усі суперечливі ситуації вирішуються на користь офіційних конвенцій Microsoft для мови C#.

## 2. Іменування. 
| Сутність | Конвенція | Приклад | Антиприклад |
| :--- | :--- | :--- | :--- |

| Інтерфейс | I + PascalCase | `ICourseRepository`| `Repository` |

| Локальна змінна | camelCase | `totalAmount` | `ta` |
| Константа | PascalCase | `MaxSeats` | `MAX_SEATS` |
| Перелічення | PascalCase однина | `RegistrationStatus` | `RegistrationStatuses` |

## 3. Форматування. 
1. **Відступ** — 4 пробіли; табуляція суворо заборонена.
2. **Довжина рядка** — не більше ніж 100 символів.
3. **Фігурні дужки** — стиль Allman (дужка на новому рядку), обов’язкові навіть для однієї інструкції в тілі `if`.
4. **Між членами класу** — рівно один порожній рядок.
5. **Директиви using** — на початку файлу, системні перші, невживані видаляються.
6. **Простір імен** — файлового рівня (`namespace X;`).

// погано: коментар переказує код

## 5. Структура проєкту. 
Проєкт розділено на два основні модулі:
* **`OnlineCourses.Core`** — містить сутності, бізнес-логіку та статуси. Не залежить від інтерфейсу користувача.
* **`OnlineCourses.App`** — відповідає за взаємодію з користувачем, консольне меню та виведення звітів.

## 6. Правила комітів.
* Повідомлення комітів пишуться українською мовою з використанням стандарту Conventional Commits.
* Кожне повідомлення починається з префікса типу (`feat:`, `chore:`, `fix:`, `docs:` тощо), після якого через пробіл іде короткий опис зроблених змін.
* Приклад правильного коміту: `feat: додано доменний скелет варіанта` або `chore: додано .editorconfig зі стилем проєкту`.
* Приклад неправильного коміту: `фікс`, `додала файли`,  або `нова фіча`.

## 7. Правила, закріплені машинно.
За дотриманням стандарту стежать налаштування `.editorconfig` та статичні аналізатори (StyleCop).

| :--- | :--- | :--- |
| Відступ 4 пробіли | .editorconfig | `indent_size = 4` |
| Приватне поле з _ | аналізатор іменування | `IDE1006` |

| Немає зайвих пробілів| StyleCop | `SA1028` |

# OnlineCourses

Навчальний проєкт із дисципліни «Конструювання програмного забезпечення». Варіант № 17: реєстрація слухачів на онлайн-курси.

## Склад рішення

- `OnlineCourses.Core` — доменна модель, прикладні сервіси, правила пакетної ціни та звітність.
- `OnlineCourses.App` — консольний інтерфейс для основних сценаріїв.
- `OnlineCourses.Tests` — модульні тести доменних правил і сервісів.
- `docs/spec.md` — специфікація функцій і сценаріїв використання.
- `docs/architecture.md` — архітектура та залежності.
- `docs/engineering-decisions.md` — журнал інженерних рішень.

## Вимоги

.NET SDK 8.0 або новіший, Git.

## Складання та запуск

```bash
dotnet restore OnlineCourses.slnx
dotnet build OnlineCourses.slnx -c Release
dotnet run --project OnlineCourses.App
```

Після запуску доступні операції зарахування, відрахування, переведення до іншої групи, звіт наповнюваності, пакетний розрахунок, пошук зарахувань і завершення курсу. Демонстраційні слухачі, курси та групи створюються в пам'яті під час запуску; дані не зберігаються після завершення процесу.

## Тести та форматування

```bash
dotnet format OnlineCourses.slnx --verify-no-changes
dotnet test OnlineCourses.Tests/OnlineCourses.Tests.csproj -c Release
dotnet test tests/Legacy.Tests/OnlineCourses.Legacy.Tests.csproj -c Release
```

## Конвеєр CI

GitHub Actions виконує відновлення залежностей, перевірку форматування, складання Release з аналізаторами, запуск тестів і перевірку порога покриття рядків 70 %. Звіт покриття зберігається як артефакт запуску CI.

## Документація

Докладний опис вимог, сценаріїв, обмежень і бізнес-правил наведено в `docs/spec.md`. Ставки пакетної знижки 5 % для двох курсів та 10 % для трьох і більше є проєктним припущенням, оскільки варіант у методичці не задає конкретних числових ставок.

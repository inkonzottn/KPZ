# Журнал інженерних рішень

Цей файл є коротким індексом рішень для поточної реалізації. Розгорнуті ADR із контекстом, альтернативами, наслідками й статусом зібрані в [decisions.md](decisions.md). Метрики рефакторингу попереднього модуля наведені в [metrics.md](metrics.md).

| Тема | Поточне рішення | Де реалізовано / перевірено |
|---|---|---|
| Шари застосунку | Три збірки: Core, App, Tests; Legacy-код винесено в окремий проєкт | `OnlineCourses.slnx`, `src/Legacy`, архітектурні тести |
| Домен | Окремі сутності Course, CourseGroup, Member та Enrollment | `OnlineCourses.Core/Domain` |
| Бізнес-операції | Зарахування, відрахування, переведення, завершення й анулювання виконуються через сервіси | `OnlineCourses.Core/Services` |
| Зберігання | JSON-файл із seed-даними; робочі зміни зберігаються між запусками | `JsonEnrollmentRepository` і тести репозиторію |
| Час | Поточний час передається через `IClock` | `OnlineCourses.Core/Abstractions` |
| Журналювання | Події аудиту передаються через `IAuditLogger` | `FileAuditLog` та тести |
| Пакетна ціна | Окрема політика з припущеними ставками 0 %, 5 %, 10 % | `CoursePackagePricingPolicy`; ставки слід погодити, якщо методичка/викладач задає інші |
| CI | Format, Release build із `-warnaserror`, Legacy та основні тести, поріг coverage 70 % | `.github/workflows/ci.yml` |

## Важливі обмеження

- Core і App наразі розташовані в корені репозиторію; лише Legacy та додаткові тестові проєкти мають окремі каталоги `src/` і `tests/`. Це фактична структура рішення, а не повністю уніфікована структура `src/`/ `tests/`.
- Покриття 95,86 % рядків, 100 % гілок і 92,85 % методів стосується лише класів, явно перелічених у параметрі `Include` workflow. Його не можна трактувати як покриття всього рішення.
- Пакетні ставки є проєктним припущенням, а не значеннями, заданими в методичці.
- Відомий борг і невиконані критерії не приховуються: див. [self-check.md](self-check.md) та [tech-debt.md](tech-debt.md).

# Журнал інженерних рішень

Актуальний журнал для самостійної роботи № 3 ведеться у файлі [decisions.md](decisions.md), який містить сім рішень у форматі «контекст — розглянуті варіанти — рішення — наслідки — статус».

Цей файл збережено як сумісне посилання з попереднього етапу репозиторію. Для оцінювання й актуального стану слід використовувати саме `docs/decisions.md`.

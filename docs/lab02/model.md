# Класова модель OnlineCourses

## Таблиця сутностей

| Сутність | Роль | Незмінний | Інваріант |
| :--- | :--- | :--- | :--- |
| `RegistrationItem` | позиція документа | так, record | `Quantity > 0`, `UnitPrice >= 0` |
| `Registration` | документ зі станом | ні, агрегат | `DocumentId > 0`, наявність хоча б однієї позиції |
| `Member` | довідник учасників | так, record | `Email` містить `@` |
| `Course` | довідник обліку | ні (змінюється залишкова кількість) | `Stock >= 0`, `Price > 0` |

## Стани документа

| Зі стану | До стану | Умова |
| :--- | :--- | :--- |
| `New` | `Confirmed` | є хоча б одна позиція та перевірено дані клієнта |
| `New` | `Cancelled` | скасування користувачем або адміністратором |
| `Confirmed` | `Paid` | успішне зарахування коштів |
| `Paid` | `Active` | курс розблоковано та розпочато навчання |
| `Active` | `Refunded` | повернення коштів не пізніше 14 днів |
| `Confirmed` | `Cancelled` | скасування перед оплатою |

# Метрики модуля «до» рефакторингу

## Розрахунок цикломатичної складності методу Handle

| Точка | Кількість |
|-------|-----------|
| `if (items != null)` | 1 |
| `if (items.Count > 0)` | 1 |
| `if (state == "new" \|\| state == "paid")` та оператор `\|\|` | 2 |
| `if (clientMail != null && ...)` та оператор `&&` | 2 |
| цикл `for` (підсумок позицій) | 1 |
| `if (vip)`, `else if (staff)`, `else if (clientDone > 10)` | 3 |
| три перевірки межі знижки `if (... > 500m)` | 3 |
| `if (_tmpSum - _tmpDiscount < 1000m)` | 1 |
| цикл `for` (формування тексту) | 1 |
| `if (sendMail)` | 1 |
| **Разом точок розгалуження** | **16** |

**CC = 1 + 16 = 17**

## Таблиця метрик «до»

| Метод | LOC | CC | Глибина вкладеності | Параметрів |
|-------|-----|----|---------------------|------------|
| Handle | 92 | 17 | 4 | 11 |
| Preview | 40 | 9 | 2 | 3 |
| DescribeClient | 16 | 3 | 1 | 1 |
| DumpLog | 9 | 2 | 1 | 0 |
| Клас загалом | 163 | — | — | — |

Інші методи: `Preview` = 1 + (foreach 1 + вид клієнта 3 + межа знижки 3 + доставка 1) = 9; 
`DescribeClient` = 1 + 2 if = 3;
`DumpLog` = 1 + foreach = 2.


- **Відповідальності класу (7):** перевірка вхідних даних, арифметика
  (сума позицій), розрахунок знижок, розрахунок доставки, форматування
  текстового звіту, журналювання, опис клієнта.
- **Дублювання між `Handle` і `Preview`:** 35 рядків логіки повторено
  (5 рядків суми + 30 рядків знижки й доставки); відрізняються тільки
  іменами змінних.
- **Магічні числа:** 7 різних значень (`0.15m`, `0.30m`, `0.05m`, `500m`,
  `1000m`, `60m`, `10`), усього 24 входження: по 12 у `Handle` і `Preview`
  (`500m` зустрічається по 6 разів у кожному).

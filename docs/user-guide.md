# Посібник користувача OnlineCourses

## 1. Запуск застосунку

Потрібні Git і .NET 8 SDK. У корені клонованого репозиторію виконайте:

```bash
git clone https://github.com/inkonzottn/KPZ.git
cd KPZ
dotnet build OnlineCourses.slnx -c Release
dotnet run --project OnlineCourses.App
```

Після запуску відкривається консольне меню OnlineCourses. Воно дає змогу зараховувати слухачів, відраховувати їх, переводити між групами, переглядати наповнюваність, рахувати пакетну вартість, шукати зарахування та позначати навчання завершеним.

## 2. Зарахування слухача — UC-01

Введіть команду `1`, далі ідентифікатор слухача й групи. Наприклад:

```text
Оберіть дію: 1
ID слухача: 26
ID групи: 1
Зарахування №26 створено.
```

Зарахування створюється лише тоді, коли слухач і група існують, немає іншого активного зарахування на той самий курс, виконані передумови й у групі є вільне місце. Якщо передумову не завершено, система повідомляє про це й не створює запис. Якщо група заповнена, операція також відхиляється.

## 3. Відрахування — UC-02

Оберіть команду `2`, введіть номер активного зарахування та причину:

```text
Оберіть дію: 2
ID зарахування: 1
Причина відрахування: Заява слухача
Слухача відраховано.
```

Після відрахування стан зарахування стає `Withdrawn`, а місце звільняється. Якщо запис не знайдено або він уже неактивний, система повідомить про відмову.

## 4. Переведення — UC-03

Оберіть команду `3`, введіть ID активного зарахування та ID цільової групи. Переведення можливе лише до іншої групи того самого курсу з вільним місцем. Якщо курс відрізняється, група заповнена або запис неактивний, початкове зарахування не змінюється.

## 5. Звіт наповнюваності — UC-06

Оберіть команду `4`. Для кожної групи система показує код курсу, назву групи, кількість активних зарахувань, місткість, вільні місця й відсоток заповнення. Групи без слухачів також включаються до звіту. Відраховані та завершені записи не займають місця.

## 6. Пакетна вартість — UC-04

Оберіть команду `5` та введіть ID курсів через кому, наприклад `1,2`. Система показує базову вартість, ставку та суму знижки й підсумок до сплати. Поточне проєктне припущення: один курс — 0 %, два — 5 %, три й більше — 10 %. Повтор курсу та порожній пакет не допускаються.

## 7. Пошук і завершення навчання — UC-05, UC-07

Команда `6` шукає зарахування за ім'ям або email слухача. Якщо збігів немає, виводиться повідомлення про порожній результат. Команда `7` переводить активне зарахування до стану `Completed`; повторне завершення неактивного запису відхиляється.

## 8. Повідомлення про помилки та дані

Повідомлення «Слухача з ID … не знайдено» означає, що потрібно перевірити введений ідентифікатор. Повідомлення про передумови означає, що слухач має спочатку завершити потрібний курс. Повідомлення про відсутність місць означає, що слід обрати іншу групу. Повідомлення про неактивне зарахування означає, що відрахування, завершення або переведення для нього вже недоступні.

Початкові дані беруться з `data/online-courses.seed.json`. Під час першого запуску застосунок створює робочий файл `data/online-courses.json`; усі зміни зарахувань записуються до нього. Для резервної копії зупиніть застосунок і скопіюйте `data/online-courses.json` в окреме безпечне місце. Щоб повернути початковий демонстраційний стан, зупиніть застосунок і видаліть робочий файл — наступний запуск створить його з seed-файлу. Журнал подій зберігається в `logs/application.log`.
